# 阿里云号码认证（一键登录）接入开发指南

本文档整理了接入阿里云一键登录功能的完整流程，包括华为后台配置、阿里云控制台配置及本地开发设置。

## 一、华为 AppGallery Connect 配置（获取 App ID）

> **前置条件**：必须注册华为开发者账号并完成实名认证。

1.  **登录控制台**：
    访问 [华为 AppGallery Connect](https://developer.huawei.com/consumer/cn/service/josp/agc/index.html)。
2.  **创建应用**：
    *   点击 **"我的应用"** -> **"新建"**。
    *   **应用名称**：填写项目名称（如 LingAI）。
    *   **包名**：必须与本地 `AppScope/app.json5` 中的 `bundleName` 一致（本项目为 `com.lingai.app`）。
    *   **应用分类**：按需填写。
    *   **注意**：创建后**无需**上传安装包，也**无需**提交审核发布。
3.  **获取 App ID**：
    *   创建成功后，进入 **"应用信息"** 页面。
    *   复制 **"App ID"** 字段（19 位纯数字，通常以 `1` 开头）。此 ID 将用于阿里云后台配置。

## 二、阿里云号码认证控制台配置（获取密钥）

1.  **登录控制台**：
    访问 [阿里云号码认证服务控制台](https://dypns.console.aliyun.com/)。
2.  **添加认证方案**：
    *   点击 **"新增号码认证方案"**。
    *   **操作系统**：选择 **HarmonyOS**。
    *   **包名**：填写 `com.lingai.app`（需与华为后台一致）。
    *   **AppId**：填写上一步从华为后台获取的 19 位 App ID。
    *   **包签名**（SHA256指纹）：
        *   **Debug 开发环境**：`CFA25979D6BA0BEC9E286CAC6CF6EF6FA88E72F7A871182543F7E4444286C748`（已移除冒号）。
        *   **Release 正式环境**：需使用 release 证书对应的指纹（可通过 `keytool -printcert -file release.cer` 获取）。
3.  **获取 Secret Key**：
    *   方案创建成功后，在列表页查看并复制 **密钥 (Secret Key)**。

## 三、本地项目配置

1.  **配置依赖**：
    *   确保 `entry/libs/China_Ali_PNVS.har` 存在。
    *   执行 `ohpm install` 或在 IDE 中点击 Sync。
2.  **配置密钥**：
    *   打开 `entry/src/main/ets/utils/Constants.ets`。
    *   替换 `PNVS_AUTH_SECRET` 常量的值为阿里云控制台获取的密钥。
3.  **真机调试**：
    *   使用 DevEco Studio 连接真机。
    *   确保手机插入 SIM 卡并开启蜂窝数据网络。
    *   运行 App 进行测试。

## 四、常见问题

*   **错误码 600024**：终端环境检查失败。通常是因为 App ID、包名或签名与阿里云后台配置不一致。仅 Debug 证书能匹配 Debug 配置，Release 证书能匹配 Release 配置。
*   **错误码 600010**：Token 获取失败。请检查密钥是否正确，或套餐包余量是否充足。
*   **本地包名被占用**：如果华为后台提示 `com.lingai.app` 被占用，需先修改本地 `AppScope/app.json5` 中的 `bundleName`，再重新申请。
*   **Resource Pack Error**: 提示 `$string:network_info_permission_reason` 未定义。
    *   **原因**：`module.json5` 中引用的权限说明字符串在 `string.json` 中缺失。
    *   **解决**：在 `entry/src/main/resources/base/element/string.json` 中添加相应键值对。
*   **ArkTS Compiler Error (no-any-unknown)**:
    *   **原因**：HarmonyOS ArkTS 严格模式禁止隐式 `any`。
    *   **解决**：使用显式类型转换（如 `as Record<string, Object>`）或具体的接口定义。SDK 回调中若需忽略参数，请使用 `_` 前缀（如 `_msg`）。
*   **Property 'removeAuthListener' does not exist**:
    *   **原因**：部分 SDK 版本或类型定义差异。
    *   **解决**：使用 `setAuthListener(null)` (或空对象 `{...}`) 替代。

## 五、开发注意事项

1.  **密钥安全**：`Constants.ets` 中的 `PNVS_AUTH_SECRET` 仅在本地调试时填入真实值，代码仓库中应保留为空字符串或占位符，防止密钥泄露。
2.  **真机调试**：一键登录强依赖蜂窝网络。模拟器无法测试，必须使用插卡的真机，并关闭 Wi-Fi 或保证移动数据优先。
3.  **权限说明**：`module.json5` 中申请的敏感权限（如 `GET_NETWORK_INFO`）必须在 `string.json` 中提供多语言描述，否则会导致编译失败。
